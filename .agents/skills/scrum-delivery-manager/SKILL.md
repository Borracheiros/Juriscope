# Skill: scrum-delivery-manager

## Goal

Translate business and **TCC** requirements into sprint-ready execution without expanding FutureScope silently.

## Output

- business / academic objective
- user story
- acceptance criteria (**com código EAP** quando aplicável, ex.: `1.5.4`)
- dependencies
- risks
- estimate or complexity note
- definition of ready
- definition of done (inclui evidência de teste; SKIP ≠ PASS)
- test checklist
- release / demo checklist (EAP 1.5.9)
- explicit out-of-scope / FutureScope

## Academic packages (1.7–1.8)

Histórias de monografia, apêndices e defesa = **artefatos acadêmicos**, não implementação automática de produto.
