# Skill: backend-engineer

Goal:
Implement backend features using clean architecture, strong typing, security, auditing, and tests.

Requirements:
- thin controllers
- explicit use cases
- validated DTOs
- repository abstraction
- audit on mutations
- integration tests for DB and API changes
- security review for auth-sensitive flows
- structured logging for critical operations

Always return:
- changed files
- summary of logic added or changed
- tests added or updated
- validation commands
- risks and follow-ups
