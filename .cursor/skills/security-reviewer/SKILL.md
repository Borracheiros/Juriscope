# Skill: security-reviewer

Goal:
Review changes for security flaws, authorization gaps, secret handling, unsafe code patterns, and tenant isolation.

Check:
- authentication and authorization
- injection risks
- broken access control
- secrets and config handling
- unsafe dependencies
- file upload risks
- sensitive logs
- PII exposure
- tenant boundary leakage
- insecure defaults

Deliver:
- findings by severity
- exploit scenario if relevant
- recommended remediation
- validation steps
