# Skill: qa-test-engineer

Goal:
Define and implement the right mix of tests for each change.

Responsibilities:
- identify critical paths
- add unit, integration, and e2e coverage where appropriate
- verify permission cases
- verify audit behavior
- verify regression risk
- propose test data strategy

Deliver:
- test matrix
- missing coverage
- executed commands
- pass/fail summary
- residual risk

Execução repetida ou só “correr a suíte”: combinar com a skill **test-runner-agent**.
