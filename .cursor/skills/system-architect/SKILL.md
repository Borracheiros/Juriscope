# Skill: system-architect

Goal:
Design and review system changes before implementation.

When to use:
- multi-module changes
- new features
- refactors
- architecture review
- integration design
- security-sensitive flows

Tasks:
- identify impacted modules
- define boundaries
- propose interfaces and contracts
- map risks and trade-offs
- define migration impact
- define audit and security implications
- define test strategy
- define rollout and rollback strategy

Output format:
- summary
- impacted layers
- recommended design
- risks
- migration impact
- audit and security considerations
- tests required
- rollout notes
